# 결 (Gyeol) · 나의 인디 결을 찾아 디깅하자

> 감상을 기록하면 AI가 **'음악을 듣는 결'**(분위기·상황·이유)을 읽고, 같은 결의 사람과 새로운 인디 음악으로 이어 주는 서비스

**▶ 바로 써 보기: https://b-side-rosy.vercel.app** (이메일 인증 없이 10초 가입, 로그인 없이도 검색 가능)

생성형 AI 해커톤 · 주제 2. **AI로 만드는 맞춤형 추천**

---

## 1. 어떤 문제를 풀까

인디 음악을 좋아하면 추천받기도, 이야기 나누기도 어렵습니다.

| 문제 | 왜 생기나 |
|---|---|
| **추천에 안 뜬다** | 기존 추천은 "이 곡을 들은 사람이 저 곡도 들었다" 방식이라, 듣는 사람이 적은 인디는 데이터가 적어 추천 목록에 잘 나오지 않는다 |
| **이유를 모른다** | 왜 이 곡을 추천했는지 설명이 없다. 장르 이름만으로는 내가 좋아하는 '결'을 찾기 어렵다 |
| **나눌 사람이 없다** | 주변에 같은 인디를 듣는 사람이 드물고, 감상을 남겨 같은 결의 사람을 만날 곳이 없다 |

## 2. 누구를 위해

- 인디를 좋아하지만 **주변에 같이 듣는 사람이 없는** 리스너
- 알고리즘 추천 말고 새 인디를 **직접 '디깅'**하고 싶은 사람
- 멜론·스포티파이·유튜브 뮤직 등 **쓰는 앱이 달라도** 누구나

## 3. 해결: 한 바퀴 도는 4단계

```
① 검색 ──▶ ② 나의 음악 저장소 ──▶ ③ 취향으로 연결 ──▶ ④ 새로운 발견
  ▲                                                        │
  └──────────── 발견한 곡을 다시 기록 ◀─────────────────────┘
```

| 단계 | 하는 일 |
|---|---|
| ① 검색 | 아티스트·노래 검색. 음악 DB에 영어로 등록된 곡도 **한국어 원제**로 보여 줌 (Dandelion → 민들레) |
| ② 나의 음악 저장소 | 노래·아티스트마다 **감상 노트** 기록. 기본은 '나만 보기'(비공개), 원할 때만 공개 |
| ③ 취향으로 연결 | **AI가 감상 노트를 읽고 듣는 이유를 요약** → 같은 노래 · 같은 아티스트 · **같은 이유(AI)** 를 가진 사람과 연결 |
| ④ 새로운 발견 | AI가 평소와 **다른 결**의 인디를 고르고, "평소 나 vs 이 아티스트" 비교 + **그래도 통하는 공통점 하나**를 설명 |

## 4. AI가 하는 일

| AI 기능 | 설명 |
|---|---|
| 취향 분석 | 내 감상 노트 → '음악을 듣는 이유' 한 문단 요약 + 결 태그 (#비오는새벽 #분위기파) |
| 같은 이유 매칭 | 듣는 곡이 달라도 듣는 이유가 닮은 사람을 찾음 (연결에 동의한 사람끼리만) |
| 다른 결 추천 | 취향이 좁아지지 않도록 다른 결의 인디 + 공통점 + 들을 상황 + 추천곡 |
| 곡 소개 | 곡 소개와 "이럴 때 들어 보세요" 상황 추천 |
| 비슷한 아티스트·노래 | 노래 페이지에서 결이 비슷한 인디 추천 + 추천 이유 |

### AI가 지어내지 않게 하는 장치 (환각 방지)

- AI가 말한 아티스트·곡은 **음악 DB(Deezer)로 실제로 있는지 확인**한 뒤에만 보여 줌
- 준비된 후보 목록 안에서 **번호로만 고르게** 해 없는 곡을 만들 수 없게 함
- 수상 기록 같은 사실은 **출처가 있는 데이터**만 사용 (화면에 출처 링크 표시)
- 한국어 원제는 AI 추측이 아니라 **두 음악 DB(Deezer · MusicBrainz)를 음원 코드(ISRC)로 대조**해서 찾음

## 5. 기존 음악 앱 추천과 다른 점

| | 기존 추천 | 결 |
|---|---|---|
| 기준 | 재생 수 · 함께 들은 기록 | 분위기 · 사운드 · **듣는 이유** |
| 인디 | 듣는 사람이 적으면 잘 안 뜸 | 듣는 사람 수와 상관없이 추천 |
| 이유 | 설명 없음 | 왜 추천했는지, 평소 나와 무엇이 다르고 같은지 **말로 설명** |
| 사람 | 혼자 듣기 | 같은 결의 사람과 연결 → 그 사람에게서 새 음악 발견 |
| 앱 | 자기 앱 기록만 | 어떤 앱을 쓰든 사용 |

## 6. 써 보는 방법 (데모 시나리오)

1. https://b-side-rosy.vercel.app 접속 → 오른쪽 위 **[로그인] → [회원가입]** (이메일 인증 없음, 비밀번호 8자 이상 영문+숫자)
2. 홈 **[① 검색]** → "우효" 또는 "한로로" 검색 → 노래를 눌러 곡 이야기 · AI 소개 확인
3. 노래 페이지 아래 **'내 감상 노트'**에 감상을 쓰고 [저장] (공개하려면 [나만 보기] → [공개])
4. 홈 **[③ 취향으로 연결]** → **[AI로 취향 분석]** → [다른 사람과 연결하기] 체크 → **[취향이 닮은 사람 찾기]**
5. 홈 **[④ 새로운 발견]** → **[다른 결의 인디 추천받기]**

## 7. 개인정보 · 보안

- 기록 기본값은 **비공개**, 비공개 기록은 **DB 권한 규칙(Supabase RLS)** 으로 다른 사람이 읽을 수 없음
- 매칭에는 연결에 **동의한 사람의 취향 요약만** 사용 (메모 원문은 공유 안 함)
- 다른 사람에게는 이메일이 아닌 **닉네임만** 보임, 비밀번호는 암호화 저장
- AI API 키는 **서버(Vercel 환경변수)에서만** 사용, 브라우저 코드·저장소에 없음
- 공개 사용자의 AI 무제한 호출을 막는 **서버 측 요청 횟수 제한**

## 8. 기술 구성

| 영역 | 사용 기술 |
|---|---|
| 화면 | HTML · CSS · JavaScript |
| 서버 | Vercel 서버 함수 (Python, `api/`) |
| AI | Google Gemini (서버에서만 호출) |
| 로그인 · DB | Supabase (이메일 로그인, PostgreSQL + RLS) |
| 음악 정보 | Deezer API, MusicBrainz |
| 데이터 | 직접 정리한 인디 아티스트 큐레이션 56팀 (`data/bands.json`) |

## 9. 앞으로의 계획 (확장성)

- **공연으로:** 추천 아티스트의 공연 일정 연결, 같은 결의 사람과 공연 같이 가기
- **데이터 넓히기:** 큐레이션 아티스트 확대, 한국어 제목 사용자 제보, 페스티벌 라인업 연계
- **취향 타임라인:** 기록이 쌓이며 내 결이 어떻게 바뀌었는지 보여 주기
